# 生成AIの進化 — 社内発表資料

GPTからReasoning、Multimodal、Open-weight / Local AI、Agent、MCP、Vibe Coding、Harness Engineering、Loop Engineering、Evalsまでを日本語で整理したローカル閲覧用Web資料です。

## ローカルで見る

### 一番簡単な方法

このフォルダーにある **`一键启动演示.cmd`** をダブルクリックしてください。

- ローカルサーバーが起動し、ブラウザーが自動的に開きます。
- 黒いウィンドウを閉じると終了します。
- すでに起動している場合は、新しく起動せずブラウザーだけを開きます。
- `5173` が別のアプリで使用中の場合は、`5174`〜`5190` の空きポートを自動的に選びます。

### PowerShellから起動する場合

PowerShellでこのフォルダーを開き、次を実行します。

```powershell
.\start-local.ps1
```

ブラウザーが自動的に `http://127.0.0.1:5173/` を開きます。

表示はプレゼンテーション形式です。`←` `→`、`PageUp` `PageDown`、`Space`、マウスホイール、タッチ操作でページを移動できます。右下の `⛶` で全画面表示に切り替えられます。

参考資料は全20ページ（初期状態は18ページ表示）を、墨色のナビゲーション、青とティールのアクセント、明るい図解面で統一しています。ページ編集、自己紹介の編集、既存の表示・並べ替え設定も引き続き利用できます。

- 表紙のSVGは、Model・System・Engineeringの三層と、それをつなぐ流れを表現します。
- 対応ブラウザーではView Transitionsで前後のページを切り替え、Web Animations APIで内容を順に表示します。非対応環境では通常のページ切り替えになります。
- MCPの接続面、Agent Loop、選択した図の接続線に短い動きを加えています。画面外のページのアニメーションは停止します。
- スライドの詳細説明はネイティブのdialog、3D総覧の解説は部品に結びついたホログラムカードで開きます。Escapeで閉じられ、操作中は背景のページ移動キーを無効にします。
- 小さい画面や情報量の多いページはページ内でスクロールできます。横長の図は図の領域内でスクロールし、拡大・縮小ボタンも利用できます。

OSまたはブラウザーで「視差効果を減らす」が有効な場合は、動きを抑えた表示に自動的に切り替わります。印刷時は操作UIを非表示にし、表示対象のページを順番に出力します。

参考資料の全20ページに、内容に対応した操作を用意しました。年のスライダー、転換点の比較、失敗を注入するAgent / Harness、MCPのドラッグ接続、3Dの設計領域、導入条件の分岐、番号付き参考資料リストを利用できます。各ページの操作一覧は [INTERACTIONS.md](./INTERACTIONS.md) にあります。

シミュレーションは準備済みのローカルデータで動き、AIへのリクエストや業務システムへの送信は行いません。工数・制作時間は説明用の仮定です。デモは「再生」「一時停止」「1ステップ」「リセット」で操作し、ページを離れると停止します。音素材は利用者が再生した時だけ鳴ります。音は3秒の合成ベルで、説明用の日本語字幕も同梱しています。

システムのマウスポインターを常に表示し、右下の「◎」で補助のレーザーポインターを切り替えられます。スライダーやデモにフォーカスがある間、方向キーはページを切り替えません。画面外のページはキーボードのフォーカス対象から外しています。MCPはタッチ端末でもボタンを押して接続できます。

操作を促す見出しや説明帯をなくし、10ページは図そのものを直接操作する構成に更新しました。時間軸、メディア、データ経路、制御フロー、MCP、概念の組み合わせ、工数配分、立体設計図、制作サイクル、三層の障害修復に対応します。参考資料は一列の番号付きリストです。

演出のスタイルは `app/scenes.css`・`app/presentation.css`、ページ入場の処理は `app/usePresentationMotion.ts`、表紙の図は `app/CapabilityMap.tsx` にまとめています。ブラウザーAPIの参考：[View Transitions](https://developer.chrome.com/docs/web-platform/view-transitions)、[CSSの離散的トランジション](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/transition-behavior)。

「全体像」はThree.jsの3D総覧です。独立画面はローカルURLの `/atlas/` で開きます。「発展」の9節目と「構成」の10要素を切り替え、立体図とラベルから個別解説、一次資料、関連テーマ、既存スライドへ移動できます。マウス・タッチで回転とズーム、ボタンでも視点を操作できます。WebGLが利用できない場合は同じ内容の一覧に切り替わります。

内容は `app/agentAtlasData.ts`、描画は `app/AtlasCanvas.tsx`、画面は `app/AgentAtlas.tsx` にまとめています。年表はAgent研究全体の起源ではなく、LLM型Agentにつながる主要な節目です。RAGは2020年の論文公開を採用し、2025年のCoding AgentはCodexという製品公開例、2026年のHarnessは工程実践の記事公開として区別しています。参照確認日：2026-09-17。

総覧の立体図は、書架・資料、関節付きロボットアーム、操作デスク、サーバーラック、接続ハブ、検査台などのミニチュアでソフトウェアの役割を表します。KenneyのFurniture KitとFactory Kitから13モデルをCC0で同梱し、すべてローカルから読み込みます。ライセンス・素材元は `public/models/atlas/CREDITS.md`、モデルの組み立ては `app/atlasModels.ts`、役割名と画面幅別の配置は `app/atlasVisuals.ts` にあります。対象を指すと接続経路を強調し、モデル自体からも詳細を開けます。

部品を選ぶとカメラが近づき、その上に解説カードを投影します。「概要」「動作例」「設計・資料」を切り替え、19種類の架空の例を4工程ずつ再生・一時停止・前後移動できます。実際のAI呼び出しや外部操作は行いません。カードを折りたたんでも投影の位置を保ち、関連テーマを開くと対応する3D部品へ移動します。カードを閉じると元の視点に戻ります。実装は `app/AtlasHologram.tsx`、事例データは `app/atlasExamples.ts`、表示は `app/hologram.css` です。


テストでは独立したブラウザープロファイルを使い、20ページの操作・カーソル・ドラッグとタッチ・画面外での停止・全画面・dialog・モバイル幅を検証します。結果とスクリーンショットは `outputs/direct-review/` に保存されます。

## なぜローカルサーバーが必要か

この資料は単一の静的HTMLではなく、Reactによるページ操作、Mermaid図のブラウザー内描画、モジュール分割を利用しています。`file://` でHTMLを直接開く方式では、ブラウザーのセキュリティ制限によりJavaScriptモジュールや関連ファイルの読み込みが不安定になります。

ローカルサーバーを使うと、インターネットへ公開せずに、通常のWebサイトと同じHTTP環境で安定して動かせます。翻页、全画面、Mermaid図、レスポンシブ表示を維持しながら、更新後の再読み込みも速くなります。
